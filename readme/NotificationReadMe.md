## Register Device Token

This endpoint allows the client (Mobile app) to register or update a push notification token for the authenticated user.

---

### Endpoint

**POST** `[BASE_URL]/notif/token`

### Authorization

**Required:** Bearer Token (JWT)

### Request Body

The request must be sent as `application/json`.

| Field | Type | Description |
| --- | --- | --- |
| `device_token` | `string` | The unique Expo Push Token generated by the mobile device. |
| `device_os` | `string` | The operating system of the device (e.g., `ios`, `android`). |

**Example Request:**

```json
{
  "device_token": "ExponentPushToken[xxxxxxxxxxxxxxxxxxxxxx]",
  "device_os": "ios"
}

```

---

### Logic Flow

1. **Authentication:** Extracts the `user_id` from the secure context (JWT).
2. **Validation:** Binds and validates the JSON payload.
3. **Database Upsert:** Calls `CreatePushToken`
* A new record is created.

4. **Response:** Returns a success message or a standard server error.

---

### Responses

| Status Code | Description | Body |
| --- | --- | --- |
| **200 OK** | Token saved/updated successfully. | `{"message": "device token saved successfully"}` |
| **400 Bad Request** | Missing or malformed JSON payload. | `{"error": "invalid request"}` |
| **401 Unauthorized** | User is not authenticated. | `{"error": "user not authenticated"}` |
| **500 Internal Server Error** | Database connection or upsert failure. | `{"error": "Something went wrong, please try again later"}` |
